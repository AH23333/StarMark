## 拍摄小技巧

1. **遮隐私**：截图前确认 Token 输入框为空（设置页 PAT 是密码框，天然遮蔽）、URL 不含私人信息。
2. **数据量**：少于 10 条 Star 时先同步一批（有数据才有说服力）；书签可以造几个演示文件夹。
3. **一致性**：同一批截图用同一份数据与主题（除 09 深色），观感统一。
4. **裁切**：侧边栏截图裁掉浏览器其他部分，只留侧边栏面板；地址栏截图保留完整浏览器宽度。
5. **大小**：PNG 格式，单张 ≤ 500KB 为宜（过大可在 README 用 HTML 缩放显示）。
