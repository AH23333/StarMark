## P1 · 消灭最大技术债

- ✅ **F1 options 按 panel 拆分**（App.tsx 955 → 68 行组装层 + 7 个自治面板；realbrowser 冒烟通过并顺带修复 browser.close()/rmSync 偶发挂起）（App.tsx 955 行 → 布局 ~200 行）
  - `panels/AiPanel.tsx`（AI 整理：设置/运行/暂停/分组应用/导出导入/清理，完全自治）
  - `panels/RulesPanel.tsx`（规则自动标签，自治）
  - `panels/AppearancePanel.tsx`（主题/字母头像/语言/右键菜单/快捷键，自治）
  - `panels/AccountPanel.tsx`（PAT/同步频率/立即同步/重建索引，接收 state + setState + refresh）
  - `panels/StatsPanel.tsx`（统计 + 健康度展示，接收 state + health）
  - `panels/DataPanel.tsx`（备份导出导入 / 通用导出 / 清除全部，接收 notify + refresh）
  - App.tsx 保留：全局 state/health/msg/refresh + 面板组装
  - 拆分前后各跑一次 realbrowser 冒烟（防 JSX 静默失败，见阶段文档 2.11 教训）

## P2 · 可测性与复用

- ⬜ **D1/D2 搜索纯函数抽取**：doSearch/buildFolderTree 的过滤与编排抽 `core/search/query.ts`（输入 items + 参数，输出 hits），worker 只剩消息分发与 MiniSearch 调用；过滤谓词收敛 `core/search/filters.ts`（source/hidden/tags/language），worker 与 BrowseNode 共用；补 core 层单测
- ⬜ **B1+C3 作业骨架**：`core/sync/job-runner.ts` 封装防重入 + checkpoint + sleep 让出 + 错误落盘；github/bookmarks/classify/pipeline 四个状态机接入；心跳/暂停（lastBeatAt/cancelRequested）收敛到骨架
- ⬜ **C4 错误类型化**：Error 子类（AiConfigError/AiRateLimitError/AiAbortError/GhAuthError…）携带 i18n key，UI 按 name 走词典；新增 locales 错误键
- ✅ **3.2-1 options 健康报告缓存**：按 indexVersion 缓存 buildHealthReport 结果
- ✅ **3.2-2 doSearch 省 bulkGet**：worker 条目缓存已含完整 StarItem，itemToHit 直接带 description
