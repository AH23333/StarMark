\# 可扩展功能全景清单



以下是我们讨论中涉及的所有可扩展功能点，按功能域分类整理。每个功能点标注了简要说明和参考来源，方便你对照调研和规划路线图。





\## 一、收藏管理核心增强



| 功能 | 说明 | 参考 |

|------|------|------|

| 统一标签系统 | Star 和书签共用一套标签，支持颜色、Emoji、批量操作 | StarHub、My-Hub |

| 笔记系统 | 每个条目可写私人笔记 | Better GitHub Stars Manager |

| 收藏理由记录 | 记录“当初为什么收藏”，AI 可生成候选理由 | 差异化方向 |

| 批量操作与导出 | 批量加标签、删除、导出 CSV/HTML/Markdown | starmap、My-Hub |

| 来源感知智能排序 | 搜索时根据场景决定优先展示书签还是 Stars | 你的整合优势 |

| 一键互相转换 | Star 仓库可直接加为书签；书签匹配 GitHub 仓库可自动 Star | 你的整合优势 |

\## 优先级建议（如果只选 5 个）



1\. \*\*标签 + 笔记 + 收藏理由\*\* — 所有竞品标配，你的差异化基础

2\. \*\*AI 审核式分类\*\* — 避免 AI 乱分类，用户可控

3\. \*\*规则引擎自动分类\*\* — 一次配置，长期受益

4\. \*\*收藏健康度仪表盘\*\* — 提升专业感和粘性

5\. \*\*MCP 服务器\*\* — 面向 Agent 生态的前瞻布局



\*\*核心原则\*\*：先做“查找”体验的极致，再做“管理”和“AI”的深度。推荐功能可作为第二增长曲线，Obsidian 联动作为知识工作流的延伸。
